# FontSystem

Manages dynamic font loading from PCK files.

## How It Works

FontSystem reads font configuration from `public/pck_infos/fonts.json` (generated by `pack_assets.gd`), loads font PCK files via ResourceSystem, creates FontFile objects, and manages the default theme font.

Fonts are loaded asynchronously during the loading scene.

## Current Limitation

The current font asset only supports **English and Chinese** characters. **Do not use emoji in any UI text** — they will not render correctly.

## Usage

```gdscript
var font_sys: FontSystem = EnvironmentRuntime.get_system("FontSystem") as FontSystem

# Event-based (recommended)
var event_sys: EventSystem = EnvironmentRuntime.get_system("EventSystem") as EventSystem
event_sys.register(FontLoadedEvent, _on_font_loaded)

func _on_font_loaded(event: FontLoadedEvent) -> void:
    if event.font_key == "press_start_2p":
        $PixelLabel.add_theme_font_override("font", event.font)

# Synchronous check
if font_sys.is_font_loaded("ding_talk_jin_bu_ti_regular"):
    var font: FontFile = font_sys.get_font("ding_talk_jin_bu_ti_regular")
```

## Changing Fonts

To add or change fonts, check the FontSystem source code for the configuration format and PCK packing workflow.
